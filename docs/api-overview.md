# API Overview

## REST

```
/api/v1/jobs                 - Gestion des jobs
/api/v1/jobs/:id/schedule    - Planification
/api/v1/jobs/:id/execute     - Exécution immédiate
/api/v1/monitoring/health    - Santé
/api/v1/monitoring/metrics   - Métriques
/api/v1/monitoring/queues    - État des files
/api/v1/scheduled-messages   - Messages programmés
```
